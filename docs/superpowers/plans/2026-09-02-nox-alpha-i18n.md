# NOX Alpha 子项目 5：多语言调整（简/繁/越/日/泰/英）实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让用户 API 可见文案支持 6 种语言（简/繁/越/日/泰/英）——中间件语言集合调整为六种并新增泰语，补齐全部翻译 key。

**Architecture:** 沿用现有机制（源码中文做 key → `lang/{locale}.json` 解析，`__()` 取文案）。改动集中在 `app/Http/Middleware/Language.php` 的映射表、`lang/*.json` 翻译数据，以及 1 处硬编码中文。不做中间件解析重构。

**Tech Stack:** Laravel 12 (PHP 8.2+)、Pest 测试、JSON 语言文件（Laravel `__()` 翻译）。

**Spec:** `docs/superpowers/specs/2026-09-02-nox-alpha-i18n-design.md`

## Global Constraints

- 活动语言 6 种：zh-CN / zh-TW / vi / ja / th / en。`ko`/`ms`/`es` 保持现状（**不删除**）。
- **不做** accept-language 解析重构（带地区后缀如 `en-US` 的精确匹配行为保持现状）。
- 只本地化用户 API 可见的 `__()` 文案；DB 内容（文章/公告/产品）、admin 面板、用户级语言偏好均不在范围。
- 3 个 `:amount` 占位符 key 在所有语言翻译中**必须保留 `:amount`**。
- 命名空间 key（含点号，如 `admin.avatar`、`user.message.*`）走 `lang/{locale}/*.php` 分组文件，**不属于 JSON 翻译范围**，完整性测试排除它们。
- JSON 翻译基准 key 集合：**206 个** = 非点号代码 `__()` key（148）+ `lang/zh_CN.json` 既有 key（含 58 个历史/legacy key）的并集。
- 需要补翻译的 key：**59 个**（58 个已在代码中缺失 + MyTeamController 新增的 `用户不存在或关系不存在`）。

### Task 3: 翻译完整性测试（守卫）

**Files:**
- Create: `tests/Feature/TranslationCompletenessTest.php`

**Interfaces:**
- Consumes: 代码 `__()` key + 各 `lang/{locale}.json`。
- Produces: 静态检查所有 6 语言文件覆盖全部 206 个 JSON key、保留 `:amount` 占位符、抽样验证翻译生效。这是后续翻译任务的验收门。

- [ ] **Step 1: 写测试**

创建 `tests/Feature/TranslationCompletenessTest.php`：

```php
<?php

use Illuminate\Support\Facades\App;

// 从 app/ 提取全部 __('literal') 非命名空间 key
function apiTranslationKeys(): array
{
    $src = '';
    $it = new RecursiveIteratorIterator(new RecursiveDirectoryIterator(app_path()));
    foreach ($it as $f) {
        if ($f->isFile() && $f->getExtension() === 'php') {
            $src .= file_get_contents($f->getPathname()) . "\n";
        }
    }
    preg_match_all('/__\(\s*[\'"](.+?)[\'"]\s*[,)]/', $src, $m);
    $codeKeys = array_filter(array_unique($m[1]), fn ($k) => !str_contains($k, '.'));
    $zh = json_decode(file_get_contents(lang_path('zh_CN.json')), true);
    return array_values(array_unique(array_merge($codeKeys, array_keys($zh))));
}

afterEach(function () {
    App::setLocale('zh_CN');
});

it('has every API key translated in all supported locales', function () {
    $locales = ['zh_CN', 'zh_TW', 'vi', 'ja', 'th', 'en'];
    $canonical = apiTranslationKeys();

    foreach ($locales as $locale) {
        $file = lang_path("$locale.json");
        expect(file_exists($file))->toBeTrue("$file 不存在");
        $data = json_decode(file_get_contents($file), true);
        expect(json_last_error())->toBe(JSON_ERROR_NONE, "$file 不是合法 JSON");
        foreach ($canonical as $key) {
            expect(isset($data[$key]))->toBeTrue("[$locale] 缺失 key: $key");
        }
    }
});

it('preserves :amount placeholders in all non-simplified locales', function () {
    $placeholderKeys = [
        '提现金额超限，剩余个人可提现金额为 :amount',
        '提现金额超限，剩余全站可提现金额为 :amount',
        '本周提现金额超限，剩余可提现金额为 :amount',
    ];
    foreach (['zh_TW', 'vi', 'ja', 'th', 'en'] as $locale) {
        $data = json_decode(file_get_contents(lang_path("$locale.json")), true);
        foreach ($placeholderKeys as $key) {
            expect(str_contains($data[$key] ?? '', ':amount'))->toBeTrue("[$locale] 占位符 :amount 丢失: $key");
        }
    }
});

it('returns real translations for sampled keys', function () {
    foreach (['en', 'vi', 'ja', 'th'] as $locale) {
        App::setLocale($locale);
        expect(__('充值'))->not->toBe('充值');
    }
    App::setLocale('zh_TW');
    expect(__('提现'))->not->toBe('提现');
});
```
